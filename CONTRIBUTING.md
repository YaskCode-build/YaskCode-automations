# Contribuir

Aprende · Practica · Construye · Comparte.

Abre una propuesta indicando problema, origen/destino, ejecutor, costos, cuotas y permisos. Las nuevas integraciones deben explicar consentimiento, recuperación y cómo desactivar la ejecución.

Trabaja en una rama y presenta un PR. Incluye documentación en español y actualiza la versión inglesa cuando cambie el README. Usa únicamente datos sintéticos. No incluyas tokens, configuración de producción ni exports.

Para código futuro: pruebas de estados, paginación, concurrencia, duplicados y recuperación con adaptadores simulados. La validación no debe requerir servicios ni credenciales reales. El workflow Validate ejecuta `npm run validate` y `npm test` sin credenciales ni llamadas de red de la integración.

La licencia MIT existente cubre esta entrega. Cualquier propuesta de licencia documental distinta deberá incorporar sus términos explícitos antes de adoptarse.


## English

Contributions to documentation, translation, accessibility, tests and integrations are welcome. Use a branch and PR; explain source/destination, runtime, costs, quotas, permissions, consent and recovery. Update Spanish and English documentation together. Use synthetic data only; never submit tokens, production configuration or exports.

Run `npm run validate` and `npm test` with Node.js 22 or later. Tests mock external services. Follow SECURITY.md for vulnerabilities. Existing MIT licensing applies to this edition; proposed documentation licensing changes require explicit terms before adoption.
