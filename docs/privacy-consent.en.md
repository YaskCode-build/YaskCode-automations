# Privacy and consent

[Español](privacy-consent.md)

Email identifies contacts for reconciliation; it does not prove consent for additional uses. Imported beehiiv newsletter state and HubSpot native marketing consent are separate concepts.

Before installation define purpose, minimum fields, responsible parties, retention and data-request handling. Do not reactivate unsubscribed contacts automatically or erase unrelated CRM relationships. V4 blocks automatic reactivation and limits updates to integration-owned properties.

Fixtures, issues, shared screenshots and logs must contain synthetic data only. Never publish exports, full API responses, private identifiers or tokens. Apps Script editors must be trusted: Script Properties does not prevent an editor from executing code that reads its values.
