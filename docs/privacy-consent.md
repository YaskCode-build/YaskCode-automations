# Privacidad y consentimiento

[English](privacy-consent.en.md)

El correo identifica contactos para reconciliación; no demuestra por sí solo consentimiento para nuevos usos. El estado importado de beehiiv y los consentimientos nativos de marketing de HubSpot son conceptos distintos.

Antes de instalar, documentar finalidad, campos mínimos, responsables, conservación y atención de solicitudes. No reactivar automáticamente bajas ni borrar relaciones CRM ajenas a la newsletter. La revisión inicial de V4 encuentra reactivaciones bloqueadas y actualizaciones limitadas a propiedades propias; falta validar la copia final.

Fixtures, issues, capturas y logs compartidos deben usar datos sintéticos. No publicar exportaciones, respuestas completas de API, identificadores privados ni tokens. Los editores de Apps Script deben ser personas de confianza: Script Properties no impide que un editor ejecute código que lea sus valores.
